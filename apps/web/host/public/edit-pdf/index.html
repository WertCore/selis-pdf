    Tool

    Last export

    The file the last export produced. The download starts as soon as you press the button, and this link takes it again. To put it somewhere you choose, right-click the link and use your browser's own Save as....

    Form fields

    Read the form's fields and fill them in. The values are written into the document on this device; viewers rebuild the field appearances when they open it.

    Read the fields to fill them in.

    Bookmarks

    The document's bookmarks — what a reader sees in their sidebar. A bookmark that points at a named destination is shown, but it cannot be edited here.

    Read the bookmarks to edit them.

    Page size

    Crop the selected page by removing margins, in points, or resize it to a named size.

    Page labels

    The number a reader sees in the page box — the roman numeral of a front matter, the figure of a chapter.

    Page numbers

    A number on every page, where the reader expects it.

    Several pages per sheet

    Put the pages side by side on a bigger sheet — two on one, four, six or nine. A document that was read becomes one that is printed.

    Bates numbers

    A number on every page, padded and prefixed — the legal way to mark a set of pages.

    Reduce the file size

    Rewrite the document more compactly. The pages look the same; the file is smaller.

    Header and footer

    A line at the top or the bottom of every page. Use {page} for the page number and {pages} for the page count.

    Watermark

    A line of text across every page — a draft mark, a confidential stamp.

    Properties

    The document's title, author, subject and keywords.

    History

    Every change, newest first. Undo returns the document to the state before it.

      Privacy report

      What the document carries about itself. The report is read on this device and changes nothing.

      Fingerprint

      What is inside the document — its pages, its fonts, its images. The report changes nothing.

      What this editor cannot do

      The text is replaced where it is drawn — the line does not re-flow, so a much longer replacement runs over what follows it. Not every line can be changed: a line drawn as several separate runs can only have one of them replaced.

      New text and images are drawn on top of of the page. A redaction removes the text under the region and covers it with a black box; anything else under it — an image, a line of art — is covered, not erased.

      Nothing leaves this device. The document is read, changed and written here, and the result downloads straight to you.
