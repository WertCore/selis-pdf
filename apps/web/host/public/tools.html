    Result

      Verified against the input structure after the write. The result is a Blob in this tab.

      What stays local

      • Your PDFs are read in this tab and copied into WebAssembly memory.
      • No request carries a document body, filename, or page text.
      • The result is downloaded with a Blob URL created here.

      The first run fetches a small WebAssembly chunk from this same site. That request has no document bytes; after it loads, the operation does not touch the network.

      Roadmap

      The rest of the toolkit.

      The feature matrix is public and staged. Each entry ships through the same local-only path; none is a link to a third-party service.

      Next

      Compress, repair, OCR

      Target-size compression, structural repair, searchable scans, and a PII scanner with review before any redaction is committed.

      Next

      Convert in both directions

      JPG, PNG, WebP, HEIC, and TIFF to PDF; PDF to JPG, text, HTML, Word, PowerPoint, Excel, and PDF/A; HTML, Markdown, LaTeX, CSV, and Office documents to PDF.

      Planned

      Secure and sign

      Protect, unlock, permissions, certificates, signatures, watermarks, Bates numbering, and page numbering — all with keys that never leave the device.

      Planned

      Organize and edit

      Crop, resize, N-up, flip, alternate and mix pages, split by size, bookmarks, text, headers and footers, flatten, invert, and page workflows.

      Planned

      Forms and review

      Fill forms, compare revisions, redact with preview, add handwriting or a thumbmark, and summarize a document without sending it away.

      Research

      Scan, share, collaborate

      Camera scan to PDF, peer-to-peer sharing, collaborative whiteboards, GST invoices, POS billing, and filing workflows.

      Selis Tools is part of the Selis PDF project. Local-only by construction, not by policy alone.
